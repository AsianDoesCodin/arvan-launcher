Arvan RPG

A jade-and-gold Minecraft RPG: classes, bosses, pets, crafting and a story that runs from Lv 1 to 200. One installer does the rest.

⬇ Download for Windows How to install
Windows 10/11, 64-bit

Install once, play forever

The launcher downloads the game, the mods and the server's resource packs for you, and keeps them current.

Automatic mods

No hunting for mod files. The launcher pulls the exact set the server needs straight from the server.

Silent updates

New versions install themselves. Play unlocks once you are on the latest release, so everyone matches.

Your own account

Pick a name and a password when you first log in. Your character stays yours.

Graphics presets

Choose a preset that fits your PC. The same setting is also in the in-game Esc menu.

Install in four steps

  1. Download the installer with the button below.
  2. Run it. Windows may show a "protected your PC" notice because the installer is not code-signed. Choose More info, then Run anyway.
  3. Log in with a name and a password (8 characters or more). The launcher downloads the game and mods the first time.
  4. Press Play. After that, updates install themselves.
